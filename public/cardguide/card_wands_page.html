ワンドのペイジ
Page of Wands
スタート・探求・純粋な情熱を表すカード。
青空と砂漠の中、ワンドを見上げて何かに気づいた若者。
「純粋な好奇心と情熱で、新しいことに踏み出すスタートの状態」がこのカードの核心です。

① 絵の細部と象徴

カーソルを画像に乗せると拡大して細部をご覧いただけます。

  • 🌟
    ワンドを見上げる若者（最重要）
    何かに気づいた状態アイデア・ひらめきこれから始まるエネルギー
    ワンドを手に持ち、空を見上げる若者の姿は「何かに気づいた瞬間」を表しています。アイデアが生まれ、ひらめきが走った——まさにこれから動き出すエネルギーが生まれた状態です。
    → 「アイデア・ひらめき・これから始まるエネルギー」
  • 👘
    黄色の服（希望）＋赤い羽根（情熱・自由）
    黄色＝幸福・希望赤＝情熱前向きで純粋なエネルギー
    希望を示す黄色の服と、情熱と自由を示す赤い羽根飾り。混じり気のない純粋なエネルギーと、自由に動き出そうとする前向きな状態を表しています。
    → 「前向きで純粋なエネルギー・自由に動き出す状態」
  • 🦎
    トカゲ（サラマンダー）模様（重要）
    火の象徴情熱・活力そのもの輪が閉じていない＝未完成・未熟
    服に描かれたサラマンダー（火トカゲ）の模様は、ワンドの火のエネルギーを象徴しています。ただし輪が閉じていないことに注目——それはまだ未完成・未熟な段階であることを示しています。
    → 「情熱・活力そのもの／ただし未完成・未熟さもある」
  • ☀️
    青空（クリアな状態）
    迷いが少ない素直・純粋
    雲のない青空は、迷いのない純粋でクリアな状態を表しています。深く考えすぎず、素直に動き出せる——それがこのペイジの最大の強みです。
    → 「迷いが少ない・素直・純粋」
  • 🏜️
    砂漠（冒険・未知）
    これからの世界未開の領域に踏み出す
    広がる砂漠は、まだ踏み込んでいない未知の領域を象徴しています。これから冒険が始まる——未開の世界へ踏み出す意志と可能性が示されています。
    → 「未開の領域に踏み出す」
✦

② コートカードとしての意味

Page / ペイジの役割
人物として出る場合
年下の人物、素直な人、未経験者・初心者。純粋で好奇心が強いが、経験が浅い人を指すことがあります。性別に関係なく、若々しいエネルギーを持つ人物として読みます。
役割・状況として出る場合
メッセンジャー・情報・知らせの役割。新しい情報が届く、良い知らせが来る、または自分がメッセージを届ける立場になることを示します。

③ スートと位階の意味

Wands / ワンドのスート
情熱・行動エネルギー創造

情熱と行動のスート。ペイジでは「そのエネルギーが生まれたばかりの、学び始めの段階」として現れます。

Page / ペイジの位階
少年・少女学びの途中初心者・研修生

コートカードの中で最も若い位階。愚者（The Fool）に近いエネルギーを持ち、スタート・自由・可能性がテーマです。

✦

④ リーディングのコツ

核心：「未熟さと成長のバランス」。これは本物の情熱か、行動できているか、理想だけで終わっていないかを問う。
✔これは"本物の情熱"か？一時的な興味で終わらないか？
✔行動できているか？ひらめきが実際の動きにつながっているか？
✔ただの理想で終わっていないか？経験が伴っているか？

深く考えていないことが強みです——「まずやってみる」がこのカードのテーマ。感情よりも好奇心・興味が強い状態。愚者に近いエネルギーで、スタート・自由・可能性に満ちています。

✦

⑤ 正位置の意味

Upright / 正位置
新しい挑戦夢に向かって動き出す学び・成長好奇心・探求良い知らせ
場面リーディング例
恋愛恋愛への純粋な好奇心・新しい出会いへの期待。ときめきのスタート。良い知らせが届く可能性
人間関係素直で純粋な縁が動き始める。年下や初対面の人との新しいつながりが生まれる
仕事新しい分野への挑戦・学び始め。良いアイデアやひらめきが生まれる。良いニュースが来る
自己成長やりたいことへの好奇心が高まる。まずやってみることで成長が始まる段階
✦

⑥ 逆位置の意味

Reversed / 逆位置
未熟・幼さ衝動的口だけ・理想だけ情報ミス・誤解空回り
場面リーディング例
恋愛気持ちだけが空回り、中身が伴っていない。衝動的な行動で誤解を招いている可能性
人間関係幼い言動でトラブルを招く。情報の行き違い・誤解が生じやすい状態
仕事やる気はあるが方向性がズレている。口だけで行動が伴わない、努力の方向性を誤っている
自己成長衝動的に動きすぎて失敗する。理想だけが先行し、現実が追いついていない状態
✦

まとめ

ワンドのペイジは「純粋な好奇心と情熱で、新しいことに踏み出すスタートの状態」を表すカードです。深く考えすぎず、まずやってみる——その素直さがこのカードの最大の強みです。

ワンドの10（限界・負担）→ワンドのペイジ（再スタート）という流れは、「一度限界を迎えたあと、新しい可能性に目が向く段階」を示しています。ここで軽やかな再スタートが始まります。

このカードが出たら、好奇心とひらめきを大切にしてください。未熟さは欠点ではなく、伸びしろの大きさです。まず一歩踏み出すことが、次のナイト（行動・突進）へとつながります。
